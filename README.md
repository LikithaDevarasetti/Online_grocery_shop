# 🛒 Online Grocery Shop System

This project is an **Online Grocery Shop** application built using **React.js** for the frontend. It allows users to browse grocery items, add them to a cart, and place orders. Admins can manage products and view orders.

---

## 💡 **Features**

### 🧑‍💻 User Module
- User registration & login
- Browse groceries by category
- Search and filter products
- Add products to cart
- Place orders
- View order history

### 🛠️ Admin Module
- Admin login
- Add, edit, delete products
- View and manage customer orders
- Manage user details

### ✨ Extra Features (Implemented / To be implemented)
- Image support for products
- Product ratings & reviews (optional)
- Discount coupons (optional)
- Payment gateway integration (optional)

---

## 🚀 **Tech Stack**

- **Frontend**: React.js (with React Router, Context API)
- **Backend**: Node.js, Express.js *(if backend implemented)*
- **Database**: MongoDB *(if backend implemented)*
- **Styling**: CSS
